# PUIMS — Data Dictionary (migrations 0001–0013)

Source of truth: `db/migrations/*.sql`. All timestamps are `timestamptz` (UTC instants); all hospital interpretations use `Asia/Manila`. Nothing is hard-deleted: the application role has no `DELETE` or `TRUNCATE` privilege on any table.

Common event columns (on `neb_administration`, `vent_encounter`, `tubing_event`, `diagnostic_appointment`):

| Column                      | Meaning                                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------------------------- |
| `recorded_at_device`        | When the device captured the entry (offline sync, M7).                                                  |
| `received_at_server`        | When the server received it (default `now()`).                                                          |
| `source`                    | `ONLINE`, `OFFLINE_SYNC`, `IMPORT`, `SEED` (synthetic).                                                 |
| `device_id`                 | Device that submitted it.                                                                               |
| `operational_date`, `shift` | **Computed by trigger** from the clinical event time (`classify_shift`); client values are overwritten. |

## Identity & security

| Table             | Purpose                                                          | Key columns / rules                                                                                                                                                                                                                                         |
| ----------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `staff`           | One row per person.                                              | `username` (unique, case-insensitive, `^[a-z0-9][a-z0-9._-]{2,39}$`), `role` (`CHIEF_RT_ADMIN` \| `RESPIRATORY_THERAPIST`), `status` (`INVITED` \| `ACTIVE` \| `DEACTIVATED`). Unique index allows only one non-deactivated Chief RT.                       |
| `auth_credential` | Secrets, 1:1 with staff. Readable only in the `auth` DB context. | `password_hash` (Argon2id PHC), `totp_secret_enc` (AES-256-GCM), `totp_last_step` (replay), `failed_attempts`, `locked_until`.                                                                                                                              |
| `auth_token`      | One-time activation/reset links.                                 | `token_hash` (SHA-256), `purpose`, `expires_at` (72 h), `used_at`, `revoked_at`.                                                                                                                                                                            |
| `auth_session`    | Server-side sessions.                                            | `token_hash`, `staff_id`, `device_id`, `mfa_verified_at` (NULL = second factor pending), `idle_expires_at`, `absolute_expires_at`, `reauth_at`, `mfa_failures`, `revoked_at`/`revoked_reason`.                                                              |
| `device`          | Browser profiles that have signed in.                            | `status` (`ACTIVE` \| `REVOKED`), `offline_phi_allowed` + `offline_approved_at/by` (Chief approval, M7; revoking or withdrawing revokes leases by trigger).                                                                                                 |
| `setting`         | Configuration.                                                   | Keys `tubing.interval_days` (1–60), `tubing.upcoming_window_hours` (0–336), `session.idle_minutes` (2–120), `session.absolute_hours` (1–24); ranges enforced by CHECK.                                                                                      |
| `audit_log`       | Append-only audit trail.                                         | `actor_id`, `session_id`, `device_id`, `occurred_at` stamped by trigger from request context (cannot be forged); `before_data`/`after_data` with secrets redacted; UPDATE/DELETE/TRUNCATE blocked by trigger for every role. Readable by the Chief RT only. |

## Clinical

| Table                    | Purpose                                                                                                     | Key rules                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------------ | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `patient`                | Patient identity.                                                                                           | `hospital_patient_id` **optional** (U-13), unique (trimmed, case-insensitive) when present; `sex` ∈ M/F only (U-07), NULL = not recorded (imports awaiting review); `category` ∈ OPD/INP/OTHER; `provenance` ∈ MANUAL/IMPORT/SEED; identity changes (name, DOB, sex, hospital no.) require `app.change_reason`; `updated_at` maintained by trigger; void columns instead of deletion.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `patient_revision`       | Append-only correction history.                                                                             | `changed_by`, `reason`, `before_data`/`after_data` for identity and location fields; written by trigger; UPDATE/DELETE blocked.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `shift_assignment`       | Roster.                                                                                                     | Unique active (date, shift, staff); removals are soft (`removed_at`, `removed_by`, `removal_reason`). Chief RT only (RLS).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `neb_order`              | Clinician's order as transcribed **by an RT** (U-17).                                                       | `prescribed_times time[]` exactly as written; PRN orders cannot carry times; never edited — `discontinued_at/by/reason` instead (trigger + RLS: RT only, in own name).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `neb_administration`     | A **documented** outcome only (expected doses are derived from `neb_order.prescribed_times`, never stored). | Reason required for NOT_GIVEN/REFUSED/CANCELLED/DELAYED; COMPLETED requires `actual_at`; author = session user (RLS); one outcome per (order, slot) while not voided; immutable after insert except a one-time void (`voided_at/by`, `void_reason`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `vent_encounter`         | Ventilator encounter.                                                                                       | `status` generated from `disconnected_at`; disconnection ≥ hook-in; no overlapping encounters per patient (exclusion constraint); responsible RT = session user; only the disconnection may be added later (trigger).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `tubing_event`           | Documented change-of-tubing (ventilator circuit) installation/replacement.                                                              | `interval_days` in force at the time; `next_due_at` computed by trigger; not before hook-in; author = session user; immutable except a one-time void with reason (voided entries never count towards the due date).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `diagnostic_appointment` | PFT / ABG / sputum induction appointments.                                                                  | `raw_status` and `raw_age_sex` kept beside normalized values; `procedure_label` as recorded. While open, `scheduled_at`, `procedure_label`, `requesting_physician`, `category` and `remarks` may be corrected with a reason (`correction_reason`, required by trigger; previous values in the audit log; not once a PFT record is signed). Status workflow enforced by `diag_status_allowed()`; closed statuses (completed, no-show, cancelled, rescheduled) never change; reason (`status_reason`) required for cancelled / no-show / for-reschedule (online entries). Reschedule = original marked RESCHEDULED + one live follow-up (`reschedules_id`, same patient + service). Corrections by void (`voided_at/by`, `void_reason`). `payment_class` optional (U-09 approved 2026-11-23; migration 0011 lifted the 0009 guard). `contact_note`: contact exactly as written (U-08), shown only on the appointment page, views audited. `import_row_id` = provenance. |
| `shift_handover`         | **One per operational date + shift** (U-11).                                                                | Author must be the session user (RLS); acknowledger must be someone else; frozen once acknowledged (trigger); acknowledgment time set by the server.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `handover_item`          | Open items carried forward **by reference**.                                                                | Kinds include `NEBULIZATION_ORDER` + `slot_at` for an expected dose (derived, so referenced by order and time). Trigger verifies the reference; no items after acknowledgment; the board shows each item's live status.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `service_event_v`        | View: documented service events (read model for activity/reports).                                          | `security_invoker`, so RLS of the underlying tables applies.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

## Diagnostics, PFT record and import (Milestone 5)

| Table                | Purpose                                                                                                           | Key rules                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `signatory`          | Approved signatory directory (RTs and pulmonologists).                                                            | Chief-only writes (RLS). RT entries link to one PUIMS account (`staff_id`), one active entry per account. Never edited — only deactivated. Synthetic entries in dev/test.                                                                                                                                                                                                                                                                                                                                                       |
| `pft_template`       | Versioned facility header, address, form revision, optional bronchodilator statement, form code `AS-PUL-PFT-006`. | Append-only (UPDATE/DELETE blocked). `hospital_confirmed` is the Chief's attestation. Each form references the version it was created with.                                                                                                                                                                                                                                                                                                                                                                                     |
| `pft_form`           | The PFT clinical record (official record, U-10).                                                                  | One live form per PFT appointment. `DRAFT` (author edits, optimistic concurrency) → `RT_SIGNED` (author signs as their own signatory entry, step-up; content frozen) → `FINAL` (an RT records the pulmonologist from the directory, the transcribed interpretation and `pulmo_signoff_method` = `E_SIGNATURE_APPLIED_BY_RT` (pulmonologist's approved e-signature, requires their image) or `WET_SIGNATURE_ON_PRINTED_COPY`; step-up). FINAL is immutable and cannot be voided. Interpretation can only be set at finalization. |
| `pft_form_amendment` | Corrections/additions to a FINAL record.                                                                          | Append-only; section, text, reason, author, time; only on FINAL forms.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `import_batch`       | One staged workbook.                                                                                              | `file_sha256` (same file cannot be live twice), `sheets` (header row, headers, column mapping), `options` (reviewer declarations: date order, workbook year, 24-h times, default category), `status` STAGED → COMMITTED → VOIDED, or DISCARDED. Chief-only (RLS).                                                                                                                                                                                                                                                               |
| `import_row`         | One source row.                                                                                                   | `sheet_name`, `row_number`, `raw` (cell values by column index — contact and payment columns removed), `parsed`, `flags`, `resolved` (reviewer values), `decision` (PENDING/ACCEPT/REJECT + reason), `patient_link` (NEW / EXISTING / SAME_AS_ROW), `appointment_id`, `created_patient`. Raw values can only ever be removed, never edited; rows of a closed batch are frozen. Decisions audited without raw values.                                                                                                            |

## Offline (Milestone 7)

| Table           | Purpose                                                           | Key rules                                                                                                                                                                                                                                                                                       |
| --------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `offline_lease` | Permission for one staff member on one device to capture offline. | ≤ 12 h and ≤ session; `key_enc` = AES-256-GCM(`PUIMS_DATA_KEY`) of the device key (redacted from the audit log); `revoked_at/reason` (device revoked, approval withdrawn, replaced).                                                                                                            |
| `sync_event`    | Every entry received from an offline device.                      | Primary key = client entry id (idempotency). `kind` (NEB_DOSE, TUBING_REPLACEMENT), `payload`, `recorded_at_device`, `clock_skew_ms`, `outcome` (ACCEPTED, DUPLICATE, CONFLICT, REJECTED), `message`, `record_id`; resolution once (`APPLIED` or `NOT_APPLIED` + note). Never edited otherwise. |

## Database functions

| Function                        | Purpose                                                                                                                                                                  |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `classify_shift(ts)`            | Asia/Manila shift + operational date (tested against the app at every boundary).                                                                                         |
| `operational_day_bounds(date)`  | `[06:00, 06:00 next day)` Manila.                                                                                                                                        |
| `app_active_staff_id()`         | The staff id only if the request's session is valid, MFA-verified, unexpired, unrevoked, on an active device, for an ACTIVE account. Basis of every clinical RLS policy. |
| `name_key(text)`                | Order-insensitive, punctuation-free name key used only to surface possible duplicates for human review.                                                                  |
| `app_is_chief()`                | `app_active_staff_id()` belongs to the Chief RT.                                                                                                                         |
| `app_is_rt()`                   | `app_active_staff_id()` belongs to a Respiratory Therapist.                                                                                                              |
| `diag_status_allowed(from, to)` | The diagnostic status workflow (mirrored and cross-checked by a test in `src/server/diagnostics.ts`).                                                                    |
| `diag_history(appointment)`     | Status-only history of one appointment from the audit log, for any signed-in user (the audit log itself is Chief-only).                                                  |
